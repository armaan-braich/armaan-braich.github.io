Hardware Accelerated DNN

Verilog · Quartus · ModelSim

This project is a fully optimized DNN hardware accelerator built using SystemVerilog for FPGA development. The goal was to create a hardware solution that could significantly speed up Deep Neural Network (DNN) inference on embedded systems. I’m passionate about improving computational efficiency, and this project gave me the opportunity to dive deep into hardware design, optimizing every detail of the data path and memory hierarchy. The accelerator handles matrix operations and memory management to allow the CPU to focus on more complex computations. One of the key achievements was achieving a 100% speedup over an older implementation by doubling the interfaces working on the computations. To ensure correctness and reliability, the program was tested thoroughly against testbenches to verify that all data transitions, memory operations, and calculations were performed as expected under different conditions.

Result of the edge detection from the DNN, visualized using a VGA wrapper. The hardware accelerators were meant to optimize the performance of the neural network.
