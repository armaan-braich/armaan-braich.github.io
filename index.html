Tempest

Kotlin · AWS · Node.js

Created an app called Tempest that allows users to get updates on natural disaster events near them. Users can easily track wildfires, earthquakes, tornadoes in their area, create custom markers, and comment on weather event markers to add critical information. Users can enable notifications to get real-time push notifications using Firebase Console. Uses Google authentication for profile creation. Utilizes a server backend hosted on AWS. Full stack development, including backend API points for notification sending, profile saving, etc.

Full-Stack Messenger

Javascript · Node.js

Created a messenger Web application which allows users to form groups and message each other. Used a dynamic Single Page Application process to offer a seamless user experience. Used a Mongo Database, with secure password storage using salted hashing. Connected to a backend with middleware, hosted using node.js. Furthermore, all inputs were sanitized to prevent against XSS attacks. Cookies authenticated users and allowed users to return to the site, even after long periods of time. Also implemented infinite scroll. Lastly, incorporated an AI model Opus-MT for easy translation supported for over 100 different languages. This allows all users to connect, regardless of language barriers.
