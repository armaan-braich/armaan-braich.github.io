Chess Game

Python · Pygame

This project is a fully functional chess game built entirely using Python and Pygame, without relying on any external libraries or frameworks. All game logic—including legal moves, pin detection, checks, checkmates, and various draw conditions—is implemented from scratch.

The game supports every core rule of chess: en passant, pawn promotion, castling, threefold repetition, insufficient material draws, and the 50-move rule. Whether you're looking for casual play or an in-depth engine-assisted analysis, this project has you covered.

For move suggestion and deeper gameplay insight, I integrated the Leela Chess Zero engine. The game can suggest optimal moves in real time, making it useful for analysis or improving your play.

Basic unit tests were also written to verify move legality, state transitions, and draw condition handling. This ensures the game logic behaves consistently under various scenarios.
