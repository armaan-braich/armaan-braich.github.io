Baccarat

Verilog · Quartus · ModelSim

The game features a custom-designed state machine that controls the game flow, including dealing cards, evaluating hands, and determining win/loss outcomes based on Baccarat rules. The datapath, hand scorer, and dealer logic were all implemented from scratch in Verilog.
To ensure correctness and reliability, each module was rigorously tested using ModelSim testbenches. These testbenches achieved 100% statement, branch, and toggle coverage through comprehensive input space exploration and regression testing, ensuring old bugs did not reappear. This validated the hardware logic's accuracy across all scenarios.
