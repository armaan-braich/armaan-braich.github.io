Messenger Web App

Javascript · Node.js · Mongo

This project is a fully-featured messenger web application designed for seamless real-time communication within groups. Built as a dynamic Single Page Application (SPA), it delivers a smooth and responsive user experience without page reloads.

The backend, developed with Node.js, connects to a MongoDB database and handles secure authentication using salted and hashed passwords. Cookie-based sessions allow users to remain logged in across visits, while middleware ensures clean routing and layered request processing.

All user inputs are sanitized to guard against XSS attacks, and infinite scrolling ensures scalable access to message history. A key feature of the platform is its integration of the Opus-MT AI translation model, enabling real-time message translation across 100+ languages, making communication effortless across language barriers.
