Recipe App

Javascript · CSS · HTML · SQL · Oracle

This project is a fully functional recipe tracking web application built to strengthen my understanding of SQL, relational databases, and full-stack web development. The main goal was to create a system where users could explore, save, and manage recipes while tracking ingredients and nutritional details.
I began by designing an Entity-Relationship (ER) diagram, which was used to create the relational and database schemas in Oracle SQL. The application supports user registration, login, recipe creation, ingredient tracking, shopping list generation, and user reviews, all of which are backed by the Oracle database.
A Controller-Service architecture is used to organize the backend, separating logic and database access for easier scalability and testing. This project gave me valuable hands-on experience with database normalization, user session handling, and structured full-stack development.
