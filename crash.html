crash

C · Process Management · Signal Handling

This project is a Unix-style terminal shell, developed in C, that replicates the core functionality of a standard command-line shell. It supports features such as process creation and management, job control, input/output redirection, piping, and signal handling. Built from the ground up, it involved careful attention to low-level system interactions and concurrency.

A major focus of the implementation was robust signal handling, as it was critical to proper job tracking. Ensuring correct behavior under concurrent execution required careful coordination between signal handlers and the main control flow, and includes custom signal-safe utilities, such as a signal-safe string formatting function designed for use within signal handlers.

The shell was thoroughly tested across a wide range of use cases to ensure stability and correctness, especially under concurrent job execution and complex command sequences. This project offered deep insight into Unix process control, low-level I/O, and safe systems programming practices.
