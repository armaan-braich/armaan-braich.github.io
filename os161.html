OS 161

C · Syscalls · VM · Synchronization

This project was built on the OS/161 operating system and involved developing core parts of a real kernel from scratch in C. Through this project, I implemented a wide range of functionality: system calls (e.g., execv, fork, waitpid), file handling, process lifecycle management, virtual memory handling, and synchronization primitives like locks and condition variables.
One of the key challenges was designing robust data structures and systems to keep track of system state, like process tables and file tables. This, along with ensuring proper concurrency situation handling, was essential in order to implement the low-level functionality for syscalls like waitpid. The implementation of the virtual memory system, syscalls, synchronization primitives, process management, gave me valuable experience, as well as a deeper appreciation for the inner workings of a computer.
Debugging was performed through careful kernel-level print tracing and GDB, and correctness was validated by passing official OS/161 test suites.
