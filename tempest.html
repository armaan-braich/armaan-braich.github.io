Tempest – Natural Disaster Tracking App

Kotlin · Android Studio · AWS · Node.js

Tempest is a fully featured Android application built using Kotlin in Android Studio, designed to help users track and stay informed about natural disasters in real time. The app integrates Google Authentication for secure sign-in and uses Firebase Cloud Messaging to enable push notifications, keeping users updated on emerging threats.

Disasters are displayed visually through a dynamic map powered by the Mapbox API, allowing users to explore earthquake zones, storm paths, and other critical information through an intuitive interface. All data is synced with a custom Node.js backend hosted on an AWS EC2 server, with real-time storage and querying supported by DynamoDB, also on AWS.

Testing was a key part of development, with the backend covered using Jest and mocking frameworks, and the frontend rigorously tested using Espresso. The project achieved near 100% code coverage and followed development standards to meet important non-functional requirements like scalability, performance, and reliability.
